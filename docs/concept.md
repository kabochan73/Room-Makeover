# 部屋の模様替えアプリ 構想メモ

## 概要
Three.js（React Three Fiber）を使った、部屋に家具を配置してレイアウトを作る模様替えアプリ。
ハッカソン向けプロトタイプ（`house1`）を土台に、同じ機能・同じ技術スタックのまま、フォルダ構成とコードの整理、Railwayへのデプロイまでを仕上げた「完成版」。

モチベーションの核は three.js（React Three Fiber）を触ること。3Dシーン自体の見た目や挙動は house1 のままで良く、見た目のリッチ化に追加investmentはしない。手を入れるのはその土台（整理・デプロイ）側。

## 機能リスト（スコープはhouse1と同一）
1. ログイン／新規登録（name + password。ゲスト／未ログインでのローカル保存お試しモードはなし）
2. 部屋選択（6種類：4×4 / 5×5 / 6×6 / 4×6 / 5×7 / 6×8）
3. 家具配置（カテゴリーごとに複数種類：sofa / chair / table / bed / desk / bookcase / plant / rug）
4. レイアウト管理（保存・一覧・編集・削除）
5. シェア・コピー（公開URL発行、他ユーザーが自分のダッシュボードにコピー）

## 画面フロー
1. **トップページ（紹介ページ）**：サービス紹介＋使い方（①部屋を選ぶ→②家具を配置する→③保存してダッシュボードに残せる）。ログイン／新規登録ボタン。
2. **ログイン／新規登録画面**：name + password。
3. **ダッシュボード**（ログイン後のホーム）：保存済みレイアウトをカード形式で表示。各カードに3Dビューのサムネイル画像（保存時にcanvasキャプチャ）。右上に「NEW」ボタン。カードクリックで編集ページへ。
4. **部屋選択画面**：部屋テンプレートを選択。各テンプレートは家具が何も配置されていない空の状態（壁・床・照明のみ）。
5. **家具配置画面（編集ページ）**：選んだ部屋に家具を配置。サイドバーの一番下に「Delete」ボタン。
6. **保存**：部屋＋配置した家具（位置・回転）を1つのレイアウトとして保存し、ダッシュボードに戻る。

## 家具モデルとスケール
- モデルは自作せず、[Kenney.nl Furniture Kit](https://kenney.nl/assets/furniture-kit)（CC0ライセンス、GLTF/GLB形式）を利用。
- Kenney系アセットはゲーム制作向けのグリッド基準で作られており、実寸（cm単位）に忠実とは限らない。
- 部屋サイズは標準的な大きさに固定しつつ、各家具モデルには個別の `default_scale` 補正値を持たせて見た目のバランスを調整する（DB管理、目視調整）。この方式はhouse1のまま変更しない。

## 技術スタック
- バックエンド：Laravel + Inertia（単一リポジトリ）
- フロントエンド：React + Inertia のページコンポーネント（機能別フォルダ構成。詳細は [frontend_design.md](frontend_design.md)）
- 3D部分：React Three Fiber + `@react-three/drei` + Zustand（配置した家具の状態管理）
- 認証：name / password の簡易ログイン
- DB：レイアウト（部屋テンプレート・家具配置）を保存

## シェア・コピー機能
- 各レイアウトに公開用の共有URLを発行（ログイン不要）：`/share/{share_token}`
- 共有ページ：サムネイル＋レイアウト名を表示するだけの静的ページ＋「このレイアウトを自分のダッシュボードに追加」ボタン。
- コピー動作：ログイン済みはクリックで即コピー。未ログインはログイン／登録後に元の共有ページに戻ってコピーを実行。

### 想定ユースケース
不動産屋の物件ページなどに部屋の共有URLを貼っておき、見た人がそこから家具配置をイメージ→気に入ったら自分のダッシュボードにコピーして自由にアレンジできる、という使い方を想定。

## house1からの変更点（整理のみ、挙動は変えない）
1. 部屋テンプレートの定義をバックエンドEnumに一本化（フロント側の重複定数を削除）。
2. `RoomDesignController` のインラインバリデーションをFormRequestに切り出し。
3. フロントエンドのフォルダ構成を機能（ドメイン）別に再編成（`features/` + `shared/`）。
4. デザインガイドラインとの差分（太いボーダーなど）を修正し、`design_guidelines.md` に揃える。
5. サムネイル画像をRailway Volumeで永続化できるようにする。
6. 家具の`default_scale`手動調整方式は変更しない（スコープ外）。

## スコープ外（今回もやらない）
- 壁紙・床材の変更
- 家具のスケール変更（UI操作での拡縮）
- 3Dシーンのリッチ化（マテリアル・ライティング・カメラワークの強化）
